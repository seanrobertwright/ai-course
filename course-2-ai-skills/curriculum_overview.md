# Curriculum Blueprint: Supercharging AI Agents with Skills

> **A 5-Part Masterclass on Transforming Generalist AI into Specialized Domain Experts**  
> *Format:* 5 Live Workshop Sessions (75–90 minutes each)

---

## 🧭 Course Matrix

| Session | Title | Core Skill Concept | Hands-on Lab | Student Milestone |
| :---: | :--- | :--- | :--- | :--- |
| **1** | **Demystifying Skills** | Why prompts fail at scale; Skills as SOPs + Toolbelts; The 3 Superpowers of Skills | The Prompt vs. Skill Benchmark Test | Witness an agent transform from generic helper to domain expert |
| **2** | **The Anatomy of a Skill** | `SKILL.md`, YAML Frontmatter, Progressive Disclosure, Folder Architecture | Dissecting a Real Production Skill | Inspect and understand frontmatter, scripts, and references |
| **3** | **Installing & Using Skills** | Community ecosystems; Local vs. Global skills; Automatic discovery vs. Direct triggers | Installing & Activating a Community Skill | Equip an agent with a pre-built QA or Copywriting skill |
| **4** | **Authoring Custom Skills** | Turning tribal knowledge into rules; Writing trigger descriptions; Bundling templates | Building Your First Custom Domain Skill | Author and validate a custom `SKILL.md` from scratch |
| **5** | **Testing & Team Workflows** | Skill debugging & triage; Over-triggering vs. Under-triggering; Git & Team Libraries | Capstone Skill Showcase & Team Library Pack | Publish a production-ready skill and demonstrate live |

---

## 🎯 High-Level Learning Outcomes

By the end of this course, students will be able to:
1. Explain with crystal clarity what a **Skill** is and why it outperforms traditional long system prompts.
2. Structure a standard skill directory conforming to industry standards (`SKILL.md`, `scripts/`, `references/`, `examples/`).
3. Write high-accuracy **YAML frontmatter** (`name`, `description`) that triggers cleanly without confusing the agent.
4. Apply the principle of **Progressive Disclosure** to keep agent context windows lean, fast, and cost-efficient.
5. Install, test, and manage third-party and community skills inside modern agent environments.
6. Package bespoke business processes, brand guidelines, code standards, or QA checklists into a portable, team-sharable skill package.
7. Diagnose and fix common skill errors (e.g., skill failing to activate, agent hallucinating rules, script execution errors).

## ⏱️ Live Session Structure (75–90 Mins)

Each session follows the proven live workshop format:
- **0:00 – 0:10 (10 mins):** Welcome, Live Chat Warm-up & Icebreaker Poll
- **0:10 – 0:35 (25 mins):** Interactive Slide Lecture & Real-World Metaphors
- **0:35 – 0:50 (15 mins):** Facilitator Live Screen Demo
- **0:50 – 1:15 (25 mins):** Student Hands-On Lab Sprint (Ambient music, real-time chat triage)
- **1:15 – 1:25 (10 mins):** Student Demos & Live Show-and-Tell
- **1:25 – 1:30 (5 mins):** Key Takeaway & Next Session Teaser
