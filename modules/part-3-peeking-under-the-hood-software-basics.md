# Part 3: Peeking Under the Hood — Software Basics Without the Jargon

> **Target Duration:** 60–90 Minutes  
> **Audience Background:** Zero coding experience, completed Parts 1 & 2.  
> **Primary Goal:** Demystify the files and code generated by the agent; empower students to read, understand, and safely tweak code without fear.

---

## 🎯 Learning Objectives
1. Explain the difference between **Frontend** (client) and **Backend** (server) using intuitive metaphors.
2. Navigate the **Replit File Tree** and identify key project files.
3. Learn how to "read" code visually without understanding programming syntax.
4. Safely make direct minor edits (text, colors, images) and understand how manual edits pair with agent prompting.

---

## 🖼️ Slide-by-Slide Presentation Guide

### Slide 1: Fear No Code — The Car Analogy
- **Visual:** A transparent car diagram showing the steering wheel/seats (interior/frontend) vs. the engine under the hood (backend) vs. the fuel tank (database).
- **Key Bullets:**
  - You drive a car every day without knowing how to rebuild a combustion engine.
  - Software is identical: you don't need to write every line of code to understand how it operates.
  - Opening the files in Replit won't break anything—you can always undo!
- **Speaker Script:**
  > *"Up until now, we've interacted with Replit strictly through conversation. But to truly become a confident software architect, you should not be afraid to open the hood. You don't need a mechanical engineering degree to check your car's oil or change the radio station. Today, we're going to open the file tree and see how clean and logical software actually is."*

---

### Slide 2: The Two Halves of Every Web Application
- **Visual:** Split graphic:
  - **Left (Frontend):** Browser, screen, buttons, colors, fonts, animations. *Metaphor: The Restaurant Dining Room.*
  - **Right (Backend):** Server, database queries, calculations, secret keys. *Metaphor: The Restaurant Kitchen.*
- **Key Bullets:**
  - **Frontend:** Everything the user can see, touch, click, or inspect in their browser.
  - **Backend:** The behind-the-scenes engine that processes transactions, checks passwords, and runs heavy tasks.
- **Speaker Script:**
  > *"Whenever you use an app like Airbnb or Uber, you are interacting with the dining room—the Frontend. The menus are pretty, the photos are crisp, the buttons click. But when you hit 'Confirm Booking', the order is sent back to the kitchen—the Backend—to charge your credit card, update the host's calendar, and lock the room. The two halves communicate constantly."*

---

### Slide 3: De-Coding the Replit File Tree
- **Visual:** A screenshot of Replit's file explorer with clear color-coded labels:
  - `index.html` or `App.tsx` -> The Skeleton & Screen Layout.
  - `style.css` or Tailwind classes -> The Wardrobe & Makeup (colors, spacing, fonts).
  - `server.py` or `index.ts` -> The Brain / Engine.
  - `package.json` or `requirements.txt` -> The Recipe Ingredients (list of tools downloaded).
- **Key Bullets:**
  - Files are just folders of organized text.
  - Don't worry about strange punctuation; look for human-readable words.
- **Speaker Script:**
  > *"When Replit Agent creates a project, you'll see a list of files on the left. Don't let file extensions like .tsx, .json, or .py scare you. They are just organized documents. One document describes the layout, one describes the style, and one handles the server logic."*

---

### Slide 4: How to Read Code Like an Editor
- **Visual:** An actual snippet of generated code highlighted with callouts:
  ```html
  <h1 class="text-3xl font-bold text-blue-600">Welcome to Lunch Roulette!</h1>
  <button class="bg-emerald-500 hover:bg-emerald-600 text-white py-2 px-4 rounded">
    Spin the Wheel
  </button>
  ```
- **Key Bullets:**
  - Notice the English text inside quotes: `"Welcome to Lunch Roulette!"`.
  - Notice the color cues: `text-blue-600`, `bg-emerald-500`.
  - Notice the button label: `"Spin the Wheel"`.
- **Speaker Script:**
  > *"Look at this code snippet on screen. Even if you've never coded in your life, what does this do? You can clearly spot the headline text, the button text, and even the colors! If you want to change 'Spin the Wheel' to 'Pick My Lunch!', you don't even have to prompt the agent—you can just double-click the words and type."*

---

### Slide 5: The "Hybrid Workflow" — Agent + Direct Tweaks
- **Visual:** Flowchart showing when to use which tool:
  - *Use the Agent for:* Complex logic, creating new pages, connecting APIs, fixing error loops.
  - *Make Direct Edits for:* Changing copy/typos, adjusting colors, replacing image URLs, updating phone numbers/emails.
- **Key Bullets:**
  - Faster iteration: Minor copy tweaks take 2 seconds manually vs. 30 seconds waiting for an agent re-run.
  - Zero risk: Use `Ctrl+Z` (Undo) or Replit's version history if you make a mistake.
- **Speaker Script:**
  > *"Pro creators use what we call the Hybrid Workflow. Let the AI Agent do the heavy lifting of building the structure, routing, and databases. But when you just want to fix a typo or swap out a logo, you can jump directly into the code, change the line, and see it update instantly."*

---

### Slide 6: Live Demo — Inspecting & Customizing a Live App
- **Instructor Action:**
  1. Open the app built in Part 2.
  2. Switch from the Agent chat view to the **Code Editor** view.
  3. Locate the main headline and change it by hand in the file.
  4. Change a background color class (e.g., from `bg-blue-500` to `bg-purple-600`).
  5. Save and show the live preview updating immediately.
  6. Switch back to Replit Agent and ask: *"Add an animated confetti burst whenever the primary button is clicked."* Show how the agent edits the file seamlessly alongside you.

---

### Slide 7: Student Hands-On Lab (20 Minutes)
- **Student Mission:**
  1. Open your Part 2 project in Replit.
  2. Navigate the file explorer and locate the main title or welcome text.
  3. Perform your first manual edit:
     - Change the headline text to your own custom greeting.
     - Find an image URL or icon and replace it.
     - Change a color code or theme accent.
  4. Now use the Agent to add one new interactive element (e.g., a "Share on Twitter / Copy Link" button).
