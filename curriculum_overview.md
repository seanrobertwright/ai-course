# Master Curriculum Blueprint

## 🌟 Pedagogical Philosophy: How We Teach Total Beginners

1. **"Instant Dopamine" First (Inverted Curriculum):**
   - Traditional coding starts with boring setup (installing Python, configuring PATH variables, command line errors) which causes 80% of beginners to quit in week one.
   - We invert this: **Students build and publish a working interactive web tool in the first 20 minutes** using Replit Agent. We introduce technical concepts *only after* they have felt the joy of creation.

2. **Every Concept Has a Real-World Metaphor:**
   - *API* = A Restaurant Waiter taking your order to the kitchen.
   - *Frontend* = The Restaurant Dining Room & Menu (what the customer sees and touches).
   - *Backend* = The Restaurant Kitchen (where logic, cooking, and secret recipes happen).
   - *Database* = The Restaurant Pantry & Order Ledger (where ingredients and customer tabs are remembered).
   - *Environment Variables (Secrets)* = A Lockbox behind the counter with the key kept safe.

3. **Product Manager Mindset Over Syntax Memorization:**
   - Students do not need to memorize semicolons or brackets. They learn how to write **clear specifications (Specs)**, define **user workflows**, and provide **iterative corrective feedback**.

## ⏱️ Delivery Formats

This curriculum is modular and easily formatted into:
- **6-Week Cohort Course:** 1 Module per week (90 mins live workshop + 60 mins hands-on lab).
- **2-Day Intensive Bootcamp:** 3 Modules per day (with lunch break and capstone hackathon).
- **Self-Paced Video Course:** 6 Core Episodes (approx. 20–30 mins each) + follow-along project guides.

## 🎯 Target Learning Outcomes

By the end of this course, students will be able to:
1. Articulate the difference between simple LLM chatbots (ChatGPT/Claude chat) and autonomous agentic workflows (Replit Agent).
2. Write structured, unambiguous product specifications that guide AI agents to generate error-free web applications.
3. Comfortably navigate the Replit interface (Workspace, Console, Shell, File Tree, Secrets Manager, Deployment Pane).
4. Identify and explain the three core pillars of full-stack software: Frontend (UI), Backend (Logic), and Database (Storage).
5. Securely connect external AI models (like OpenAI or Anthropic) using API keys stored in environment secrets.
6. Troubleshoot common agent failures and steer the agent back on track using error logs and screenshot-based debugging.
7. Confidently publish live, production-ready web apps with custom URLs to showcase to clients, employers, or users.
